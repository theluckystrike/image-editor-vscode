# Changelog

## 0.1.0

- First release: image editor and image resizer for PNG, JPEG, WebP, GIF (first frame) and BMP files, with crop, resize, rotate, flip, straighten, annotations (arrow, line, box, ellipse, text, pen, highlighter, numbered steps), blur and pixelate, brightness, contrast and saturation.
- Undo, Redo, Save, Save As (PNG, JPEG, WebP, BMP), Revert and hot exit work as in any VS Code editor.
- Paste an image from the clipboard as a new file.
- Zovo Pro tools with 3 free tries each: batch resize and convert a folder, compress to a target size, compare two images.
- Related Zovo extensions in "More free viewers", in the README and in the last walkthrough step. A link opens the extension page; nothing installs on its own.
