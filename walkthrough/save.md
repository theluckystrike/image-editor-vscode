# Save or convert

- Save writes the same format back to the file. JPEG and WebP use the quality from the settings (92 and 90).
- Save As writes a new file. The extension of the name you type picks the format: `.png`, `.jpg`, `.webp` or `.bmp`.
- A GIF is saved as a PNG next to it.

EXIF data such as the GPS location is not copied into the saved file.
