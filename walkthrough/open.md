# Open an image in the editor

VS Code still opens images in its own preview. To edit one:

- Click Edit Image at the top right of the preview, or
- right-click a `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif` or `.bmp` file in the Explorer and pick Edit Image.

The sample is a made-up app window. It is copied to the extension's storage first, so your edits never change the bundled file.
